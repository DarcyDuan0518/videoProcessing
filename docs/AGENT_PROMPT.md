# Agent 需求提示词

以下提示词已将项目当前的所有输入需求、已确认的运行环境和安全边界整理为可直接提供给编码 Agent 的形式。

```text
你需要实现一个用于家庭监控视频离线初筛的程序。请在本地项目中开发，并遵守以下完整需求：

【目标】
处理家庭监控视频文件。摄像头大约每十几分钟产生一个视频文件；一个目录中可能有 1–2 周、上千个视频文件。程序要批量分析这些文件，筛选是否包含人。

【运行环境与部署】
1. 当前电脑仅用于初步调试和测试；全量视频在另一台电脑。
2. 全量视频电脑为 Windows，配有 NVIDIA 显卡。优先使用 NVIDIA GPU 加速，但应提供 CPU 回退说明。
3. 所有 Python 和系统依赖、安装步骤、GPU 验证方法都必须写入文档，确保另一台电脑可通过一键安装脚本安装。
4. 推理必须在本地离线完成；不得上传、分享或删除家庭视频。

【检测和分类】
1. 第一优先级是识别视频中是否有人。可以对视频抽帧，而不要求逐帧推理；抽帧间隔和单视频最大采样数必须可配置。
2. 对读取失败的视频单独报告，绝不可把失败文件默认列入删除候选。

【夜间规则】
1. 夜晚睡觉视频的处理必须由可配置参数控制。
2. 夜间时间优先从文件名中的录制日期时间解析，而不是文件创建时间；文件名时间的正则和日期格式必须可配置。
3. 有时夜间有人视频要保留，有时不要保留。提供 `keep_videos_with_person` 一类的开关，实现两种策略。
4. 无法从文件名可靠解析时间时，不能仅依夜间规则把文件列为删除候选。

【可删除候选与安全性】
1. 没有人的视频需要被识别为可删除候选。
2. 根据配置，夜间有人视频也可被识别为可删除候选。
3. 识别程序默认、且当前版本不得删除、移动、覆盖或修改任何源视频；独立的候选移动工具在人工复核报告后可立即将候选移动至源目录的可配置子文件夹。
4. 将“认为可删除”的文件名、相对路径、原因、时间、检测统计写入一个 CSV，供人工复核。
5. 清楚提醒：候选清单不是删除许可；夜视、远景、遮挡会导致误检或漏检。

【建议交付物】
1. 一个命令行批处理程序，接收：输入视频目录、UTF-8 JSON 配置路径、报告输出目录。
2. 配置示例：模型、扩展名、递归扫描、抽帧、人体阈值、文件名时间正则、夜间时段、夜间保留策略、报告编码和可删除文件夹名称。
3. 生成一个完整报告 CSV，文件名应包含源视频目录名；同一源目录后续成功识别可覆盖旧报告，候选移动工具应自动使用该固定报告。
4. Windows 一键安装脚本、requirements 文件、部署/配置/操作文档。
5. 默认报告使用 Excel 易读的 UTF-8 BOM CSV。

【验收原则】
- 先用少量、代表性视频测试并人工抽查结果，再跑全量目录。
- 默认流程不产生任何不可逆动作。
- 文档准确列出依赖、安装方式、配置和已知局限。
- 代码应能处理上千个文件，并在单个文件失败时继续处理其余文件。
```
